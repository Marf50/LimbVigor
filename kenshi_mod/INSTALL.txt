Limb Vigor — install
====================

Needs: Kenshi 64-bit + RE_Kenshi
https://www.nexusmods.com/kenshi/mods/847

1. Download LimbVigor-INSTALL.zip from
   https://github.com/Marf50/LimbVigor/releases/latest
2. Extract the LimbVigor folder into Kenshi/mods/ so you have:

   Kenshi/mods/LimbVigor/LimbVigor.mod
   Kenshi/mods/LimbVigor/_LimbVigor.info
   Kenshi/mods/LimbVigor/LimbVigor.dll
   Kenshi/mods/LimbVigor/RE_Kenshi.json
   Kenshi/mods/LimbVigor/config.ini

   The folder name and the .mod name must match. Kenshi will not list
   a plugin-only folder.

3. Start Kenshi. On the launcher Mods tab, enable:
     RE_Kenshi
     LimbVigor
   Put LimbVigor after RE_Kenshi. Launch.

Already have the old folder without a .mod?
Drop LimbVigor.mod and _LimbVigor.info into that same folder, then
enable LimbVigor on the Mods tab. The DLL does not load unless the
mod is ticked — RE_Kenshi only starts plugins from enabled mods.

What you should see
-------------------
Open a character medical panel. Under Blood:
  Hive        — Hemolymph bar
  Shek        — Battle-heat bar
  Human       — Vigor bar
  Skeleton    — “Frames do not grow flesh.”

A stump stages: dormant → budding → forming → knitting → whole.
The new limb is original flesh at ~22% HP. First-aid it.

Hive grows if fed and bandaged.
Shek need toughness 20 or a used Splint Kit.
Humans need toughness 40 and Field Medic 25, or a used Splint Kit.
Skeletons never.

If the game crashed on load before: this build no longer talks to
town NPCs, does not call character speech, and leaves the medical
bar off. Growth still runs for your squad. After a clean load, set
EnableHud=1 in config.ini if you want the bar back.

If the game crashes on load: set EnableHud=0 in config.ini and try again.
Speech can be turned off with EnableSpeech=0.

Bug notes go in testdoc/BUGTEST.md — send them back and we patch.
