Limb Vigor — install
====================

Needs: Kenshi 64-bit + RE_Kenshi
https://www.nexusmods.com/kenshi/mods/847

1. Download LimbVigor-INSTALL.zip from
   https://github.com/Marf50/LimbVigor/releases/latest
2. Extract the LimbVigor folder into Kenshi/mods/ so you have:

   Kenshi/mods/LimbVigor/LimbVigor.mod
   Kenshi/mods/LimbVigor/_LimbVigor.info
   Kenshi/mods/LimbVigor/LimbVigor.dll
   Kenshi/mods/LimbVigor/RE_Kenshi.json
   Kenshi/mods/LimbVigor/config.ini

   The folder name and the .mod name must match.

3. Start Kenshi. On the launcher Mods tab, enable:
     RE_Kenshi
     LimbVigor
   Put LimbVigor after RE_Kenshi. Launch.
