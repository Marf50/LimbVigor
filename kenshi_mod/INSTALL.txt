Limb Vigor — install
====================

Needs: Kenshi 64-bit + RE_Kenshi
https://www.nexusmods.com/kenshi/mods/847

1. Download LimbVigor-INSTALL.zip from
   https://github.com/Marf50/LimbVigor/releases/latest
2. Extract the LimbVigor folder into Kenshi/mods/ so you have:

   Kenshi/mods/LimbVigor/LimbVigor.mod
   Kenshi/mods/LimbVigor/_LimbVigor.info
   Kenshi/mods/LimbVigor/LimbVigor.dll
   Kenshi/mods/LimbVigor/RE_Kenshi.json
   Kenshi/mods/LimbVigor/config.ini

   The folder name and the .mod name must match.

3. Start Kenshi. On the launcher Mods tab, enable:
     RE_Kenshi
     LimbVigor
   Put LimbVigor after RE_Kenshi. Launch.

Where the numbers are
---------------------
Select a character. The left medical list (Blood)
gets Hemolymph / Vigor / Battle-heat via
setLineProgress. Spoken lines appear over the
character.

I-key on a stump/bud/knit/grown item is the backup.
C is skills. Door / building: no medical row.

This build does not create widgets. No layout file.

v1.9.8: medicalPanel setLineProgress + _NV_say, no
load-time GUI hooks. v1.9.7 died in MainBarGUI ctor
(LifeBar10 / Kenshi_MainPanel.layout). No ctor, no
changeFontSize, no _NV_update, no _NV_setObject.
After orig getMedicalGUIData / _NV_getGUIData only
when In-game + character selected + Blood. Door /
non-character: do not add; removeLine on that path.
If none exists: _NV_say only. Arms even if
gameResetting stays stuck. No Character until
in-game. LimbVigor.mod records have mesh/icon.

Overwrite both LimbVigor.dll and LimbVigor.mod. Keep
LimbVigor.progress.

Hive grows if fed and bandaged.
Shek need toughness 20 or a used Splint Kit.
Humans need toughness 40 and Field Medic 25, or a used Splint Kit.
Skeletons never.

Keep LimbVigor.progress — existing growth numbers are reused.
Overwrite LimbVigor.mod as well as the DLL.


Replace the old DLL
-------------------
Quit Kenshi. Overwrite Kenshi/mods/LimbVigor/LimbVigor.dll and
config.ini. Keep LimbVigor.progress. Launch.

If it crashes, set EnableHud=0 and send the last 40 LimbVigor
lines from RE_Kenshi_log.txt.
