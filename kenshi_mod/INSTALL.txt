Limb Vigor — install
====================

Needs: Kenshi 64-bit + RE_Kenshi
https://www.nexusmods.com/kenshi/mods/847

1. Download LimbVigor-INSTALL.zip from
   https://github.com/Marf50/LimbVigor/releases/latest
2. Extract the LimbVigor folder into Kenshi/mods/ so you have:

   Kenshi/mods/LimbVigor/LimbVigor.mod
   Kenshi/mods/LimbVigor/_LimbVigor.info
   Kenshi/mods/LimbVigor/LimbVigor.dll
   Kenshi/mods/LimbVigor/RE_Kenshi.json
   Kenshi/mods/LimbVigor/config.ini

   The folder name and the .mod name must match.

3. Start Kenshi. On the launcher Mods tab, enable:
     RE_Kenshi
     LimbVigor
   Put LimbVigor after RE_Kenshi. Launch.

Where the bars are
------------------
This is NOT a bar on the portrait strip. Open the character STATS
panel — the same list that already shows Blood and Hunger.

  1. Click the character (Boop, Plop, …)
  2. Open STATS (default key C, or the stats tab on the side panel)
  3. Under Blood you should see:
       Hemolymph / Battle-heat / Vigor     (the resource bar)
       Regrowth   left leg  budding  4%
       Time       ~36h on the road. Bed is 2x.
       How        Hive: hemolymph knits on its own...

Speech is on the STATS lines (Time / How), not bubbles. Cut / stage
/ finish still print to RE_Kenshi_log.txt.

If STATS crashes, set EnableHud=0. Growth still runs.

Hive grows if fed and bandaged.
Shek need toughness 20 or a used Splint Kit.
Humans need toughness 40 and Field Medic 25, or a used Splint Kit.
Skeletons never.

A stump stages: dormant → budding → forming → knitting → whole.
The new limb is original flesh at ~22% HP. First-aid it.

Replace the old DLL
-------------------
Quit Kenshi. Overwrite Kenshi/mods/LimbVigor/LimbVigor.dll and
config.ini. Keep LimbVigor.progress (your growth save). Launch.

Bug notes go in testdoc/BUGTEST.md — send them back and we patch.
